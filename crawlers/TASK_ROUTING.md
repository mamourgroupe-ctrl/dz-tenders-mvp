# 🎯 دليل توجيه المهام الآلي (Task Routing)

## القاعدة الذهبية
لا تسأل "أي أداة أستخدم؟" — بل اسأل "ما نوع المهمة؟"

---

## 📊 جدول التوجيه

| نوع المهمة | الأداة | الأمر | أمثلة |
|:---|:---|:---|:---|
| **صغيرة/يومية** | Kilo Code (Mistral) | `dev-small` | Docstring، إصلاح typo، إضافة تعليق، تنسيق، إعادة تسمية |
| **متوسطة** | Cline | `dev-mid` | إضافة دالة جديدة، تعديل ملف واحد، كتابة اختبار |
| **معقدة/تحليلية** | `agy` (Gemini Flash) | `dev-complex` | تحليل معماري، إعادة هيكلة، debugging معقد |
| **حساسة/أمنية** | Claude Code | `dev-secure` | مراجعة كود، تحليل ثغرات، معالجة بيانات حساسة |
| **سياق/توثيق** | Context7 MCP | `dev-docs` | جلب توثيق مكتبة، مقارنة إصدارات |
